# k6 Demo API — Endpoint Reference

Base URL (local): `http://localhost:8000`
Interactive docs (auto-generated by FastAPI): `http://localhost:8000/docs`
Postman: import `postman/k6-demo-api.postman_collection.json`

All bodies are JSON. Protected endpoints need `Authorization: Bearer <access_token>` from `/auth/login`.

| Method | Path | Auth | Purpose | Success |
|---|---|---|---|---|
| GET | `/health` | – | Liveness check | 200 |
| POST | `/auth/signup` | – | Create an account | 201 |
| POST | `/auth/login` | – | Get a JWT access token | 200 |
| GET | `/users/me` | ✔ | Current user | 200 |
| PATCH | `/users/me` | ✔ | Update your name | 200 |
| GET | `/users/{user_id}` | ✔ | Get a user by id | 200 |
| POST | `/items` | ✔ | Create an item | 201 |
| GET | `/items?skip=0&limit=20` | ✔ | List your items | 200 |
| GET | `/items/{item_id}` | ✔ | Get one of your items | 200 |
| PATCH | `/items/{item_id}` | ✔ | Partially update an item | 200 |
| DELETE | `/items/{item_id}` | ✔ | Delete an item | 204 |

---

## POST /auth/signup

```json
{ "email": "ada@example.com", "password": "SuperSecret123!", "full_name": "Ada Lovelace" }
```

- `password`: 8–72 characters (bcrypt limit)
- **201** → `{ "id": 1, "email": "ada@example.com", "full_name": "Ada Lovelace", "created_at": "..." }`
- **409** email already registered · **422** validation error

## POST /auth/login

```json
{ "email": "ada@example.com", "password": "SuperSecret123!" }
```

- **200** → `{ "access_token": "eyJ...", "token_type": "bearer", "expires_in": 1800 }`
- **401** invalid email or password

## GET /users/me

- **200** → user object · **401** missing/invalid/expired token

## PATCH /users/me

```json
{ "full_name": "Ada King" }
```

## GET /users/{user_id}

- **200** → user object · **404** not found

## POST /items

```json
{ "name": "Mechanical keyboard", "description": "Brown switches", "price": 120.5, "quantity": 1 }
```

- `name` required; `price` ≥ 0; `quantity` ≥ 0
- **201** → `{ "id": 1, "name": "...", "description": "...", "price": 120.5, "quantity": 1, "owner_id": 1, "created_at": "...", "updated_at": "..." }`

## GET /items

Query: `skip` (default 0), `limit` (default 20, max 100). Returns only the caller's items.

## GET /items/{item_id}

- **404** if it doesn't exist **or** belongs to another user (so IDs of other users' items aren't leaked).

## PATCH /items/{item_id}

Send only the fields to change:

```json
{ "price": 99.99, "quantity": 3 }
```

## DELETE /items/{item_id}

- **204** no body

## curl quick test

```bash
curl -s -X POST localhost:8000/auth/signup -H 'Content-Type: application/json' \
  -d '{"email":"ada@example.com","password":"SuperSecret123!","full_name":"Ada"}'

TOKEN=$(curl -s -X POST localhost:8000/auth/login -H 'Content-Type: application/json' \
  -d '{"email":"ada@example.com","password":"SuperSecret123!"}' | python3 -c 'import sys,json;print(json.load(sys.stdin)["access_token"])')

curl -s localhost:8000/users/me -H "Authorization: Bearer $TOKEN"
```
